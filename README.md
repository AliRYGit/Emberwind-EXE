# Emberwind-EXE
A restored and modernized standalone Windows version of the classic [Emberwind HTML5 game].

## About

Emberwind is an old HTML5 game that was originally designed for web browsers of its time.

Due to changes in modern web browsers, the original version no longer runs correctly on many current browsers and operating systems.

This project focuses on restoring the original game and making it playable on modern Windows systems.

### What I changed

The original HTML5 game was modified to address compatibility issues with modern environments.

The main process was:

```text
Original Emberwind HTML5
          ↓
Compatibility issues with modern browsers
          ↓
Code restoration and modifications
          ↓
Modern standalone application
          ↓
Windows EXE
